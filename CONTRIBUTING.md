# Contributing to Desktop Accounting API repositories

Thanks for your interest. Each SDK repository has its own CONTRIBUTING.md with build and test commands. This file covers what they have in common.

- **Generated code.** The SDKs are generated from the Desktop Accounting API OpenAPI contract. Files headed `Code generated by packages/sdk-generator. DO NOT EDIT.` are overwritten on every release. Maintainers reproduce accepted changes in the generator or the hand-written runtime and credit the contributor in the changelog.
- **Issues.** Include the SDK version (for example `0.5.4`), your language runtime, the operation, and the `Daapi-Request-Id` (`req_...`) of a failing call. Every SDK error exposes it.
- **Secrets.** Never post secret keys, webhook signing secrets, Web Connector passwords or customer data in issues, pull requests, tests or logs.
- **Security.** Report vulnerabilities privately. See SECURITY.md.
- **Toolchains.** Each repository pins its toolchain in `mise.toml`. `mise install && mise run check` runs the same checks as CI.

By contributing, you agree that your contributions are licensed under the repository's MIT license.
