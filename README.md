# .github

Organization profile and default community health files for [Desktop Accounting API](https://github.com/DesktopAccountingAPI).

- `profile/README.md`: the organization profile shown on github.com/DesktopAccountingAPI.
- `ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE.md`, `CONTRIBUTING.md`, `SECURITY.md`: defaults for every repository in the organization that does not define its own.

These files are generated together with the SDK repositories. Edit them in the generator's templates, not here.
